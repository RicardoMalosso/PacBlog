Este é o começo do meu canto na internet: um lugar para reunir as coisas que construo, escrever sobre o que aprendo e abrir espaço para a música.

## O que tem por aqui

- **Portfólio:** projetos de software e as ideias por trás deles.
- **Blog:** notas de desenvolvimento e textos mais longos.
- **Música:** notas de escuta, letras e traduções com contexto.
- **Experimentos:** pequenas coisas para testar direto no navegador.

O site está disponível em português brasileiro e inglês. O seletor de idioma leva à página correspondente quando existe uma tradução.

## Feito para continuar simples

Todas as páginas são geradas a partir de arquivos do repositório e hospedadas no GitHub Pages. Não há servidor ou banco de dados para manter. Os artigos começam em Markdown; as partes interativas usam React.
